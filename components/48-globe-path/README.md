# Globe with flight paths

**Category:** Maps · **Tags:** orthographic, great circle, routes, 3D globe, draggable, canvas

A dotted orthographic globe with great-circle routes arcing out of a hub: route width = passengers, animated travellers along each path, drag to spin, auto-rotate, and a ranked route list that flies the globe to any destination.

Live demo: [`index.html`](index.html) — one self-contained file, no dependencies. Light and dark themes; add `?theme=dark` or `?embed=1` to the URL.

## Use it when
- Origin–destination data across continents (flights, shipping lanes, data-centre traffic, customer reach)
- Hero panels where a world view should feel alive
- Up to ~30 routes from a few hubs

## Avoid it when
- Comparing values precisely (pair with the route list or a bar chart)
- Regional data where a flat map shows more at once
- Low-power or print contexts (use a static flat map with arcs)

## Anatomy
- Orthographic projection on canvas; sphere in a surface tint with an axis-grey rim and a faint 30° graticule
- Land as a dot matrix (every ~2.4°), dots fade towards the limb for depth
- Routes: great-circle arcs lifted above the surface in the middle, width 1–3.5px ∝ passengers, accent colour; hidden where they pass behind the globe
- Moving travellers: small dots running along each route (off under prefers-reduced-motion)
- Hub: ink dot with a surface ring and label; destinations: accent dots
- Side list: routes ranked by passengers with bars; selecting one flies the globe to it

## Data shape
```
{ hub: { name: "Chicago", lat: 41.98, lon: -87.9 }, routes: [{ to: "London", lat: 51.47, lon: -0.45, passengers: 412000 }, …] }
```

## Interactions
- Drag to rotate (pointer events, works with touch)
- Auto-rotate toggle (off by default under prefers-reduced-motion)
- Hover a route: it turns to the second accent and a tooltip shows destination, passengers and distance
- Click a route in the list (or Enter) to fly the globe to it and highlight it

## Accessibility
- The route list carries every value as text and is keyboard operable
- Canvas has a role=img label summarising the hub and top routes
- Motion respects prefers-reduced-motion

## Design tokens used
`--s1`, `--s2`, `--surface-2`, `--axis`, `--ink`, `--ink-2`, `--grid` — defined once on `:root` in the demo, with dark-mode values.
